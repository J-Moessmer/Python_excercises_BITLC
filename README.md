This repository contains a collection of Python scripts and projects developed as exercise tasks during my time at the **Business IT Learning Center (BITLC)**. The exercises cover a wide range of topics, from basic Object-Oriented Programming (OOP) to GUI development and graphical simulations.

<br>

---

<br>

<h2 align="center">📁 Project Overview</h2>

<br>

<h3 align="center">
  <a href="./26-02-23/README.md">01. Object-Oriented Foundations & Basics</a>
</h3>

A collection of scripts focusing on the core principles of OOP, including class definitions, methods, and basic data modeling, alongside initial steps in Turtle graphics.

<br>

<h3 align="center">
  <a href="./26-02-25/README.md">02. Graphics & Random Simulations</a>
</h3>

Exercises exploring more advanced loops, randomization, and boundary logic using the `turtle` module, as well as early prototypes for GUI applications.

<br>

<h3 align="center">
  <a href="./26-02-27/README.md">03. GUI Applications</a>
</h3>

Standalone graphical applications built with Python's `tkinter` library, featuring a fully functional calculator with a custom design.

<br>

<h2 align="center">🚀 Getting Started</h2>

To run any of the scripts, ensure you have Python 3 installed. Some exercises require the `tkinter` library (usually included with standard Python installations).

```powershell
# Example: Running the calculator
python 26-02-27/01_calculator.py
```
